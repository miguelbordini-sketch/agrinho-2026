# 👾 Pac-Style Game (p5.js)

Um jogo simples estilo Pac-Man feito com **p5.js**, com mapa aleatório, jogador e inimigo com perseguição básica.

## 🎮 Como jogar

Use as setas do teclado:

- ⬆️ mover para cima  
- ⬇️ mover para baixo  
- ⬅️ mover para esquerda  
- ➡️ mover para direita  

Evite o inimigo vermelho!
